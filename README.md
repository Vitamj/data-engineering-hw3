# Инженерия данных: ДЗ 3, вариант 7 (Go-разработчик)

Исходник - архив `hh.zip` из учебного чата: 10 000 JSON-файлов с вакансиями. Здесь **не лежит** личный архив и не публикуются ключи RustFS. Скрипт `prepare.py` делает компактный JSONL с нужными для задания полями; оригинальный SHA-256 зафиксирован в отчёте. Для своего варианта отбираем названия вакансий, где Go или Golang - отдельное слово. Поиск только по навыкам дал бы ложные совпадения, например вакансии аналитиков с Go в требованиях.

## Что запустить

Нужны Python 3.12, зависимости из `requirements.txt`, локальный RustFS с S3 API на `127.0.0.1:9000` и расширение DuckDB `httpfs`. Один из вариантов запуска RustFS без Docker:

```bash
mkdir -p runtime/disk
export S3_ACCESS_KEY='ваш_локальный_ключ'
export S3_SECRET_KEY='ваш_локальный_секрет'
export S3_ENDPOINT='http://127.0.0.1:9000'
RUSTFS_ACCESS_KEY="$S3_ACCESS_KEY" RUSTFS_SECRET_KEY="$S3_SECRET_KEY" \
  rustfs server --address 127.0.0.1:9000 --console-enable \
  --console-address 127.0.0.1:9001 runtime/disk
```

Путь тома RustFS на этом Mac не должен содержать пробелы; если содержит, можно дать ему путь через символьную ссылку. Для запуска через Docker см. инструкцию RustFS из ДЗ 2. Затем в другой консоли:

```bash
python3.12 -m pip install -r requirements.txt
python3.12 prepare.py /путь/к/hh.zip --output data/vacancies.jsonl
python3.12 -c 'import duckdb; duckdb.connect(config={"extension_directory":"runtime/duckdb_extensions"}).execute("INSTALL httpfs")'
python3.12 run.py --repeats 3
```

`run.py` создаёт бакет `hh-lake`, загружает `raw/vacancies.jsonl`, читает **его** чанками из S3 в собственной реализации MapReduce, затем независимо считает размеры стека 1, 2 и 3 запросами DuckDB прямо по `s3://hh-lake/raw/vacancies.jsonl`. Программа сравнивает полные словари частот, поэтому при расхождении останавливается с ошибкой. Результаты `skills_1.json`, `skills_2.json`, `skills_3.json` сохраняются локально и в `hh-lake/results/go/`. `results/evidence.json` содержит контрольные числа, зарплатные и региональные таблицы, три замера каждого подхода.

Зарплата считается только для записей с `currency=RUR`, как середина диапазона `from`/`to` или единственная указанная граница. Это условная опубликованная зарплата, не фактический доход. Поле `gross` не унифицировано, поэтому межвакансионные сравнения ограничены. Пар/троек с 1-3 зарплатными вакансиями недостаточно для сильных выводов; отчет показывает размер группы и использует формулировку «связано с медианой», а не причинное влияние.

## Состав

- `prepare.py` - воспроизводимая подготовка 10 000 объектов архива.
- `s3.py` - минимальный клиент S3 с SigV4, только переменные окружения для ключей.
- `counts.py` - чанковый MapReduce и отдельные SQL-запросы DuckDB.
- `run.py` - загрузка, три запуска, полная сверка, региональный и зарплатный анализ.
- `report/report.pdf` - результаты фактического запуска, ограничения и выводы.

Исходный `hh.zip` и преобразованные данные исключены из Git. Для сдачи публикуются код, PDF и `results/evidence.json`; объекты результатов хранятся также в локальном RustFS и проверяются повторным `HEAD`.
